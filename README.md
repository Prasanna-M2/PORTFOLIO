# Prasanna M — Embedded Systems & IoT Portfolio

Personal portfolio website for **Prasanna M** (B.E. Electrical & Electronics Engineering, 2024–2028), highlighting embedded systems & IoT projects, industrial internships, technical skills, certifications, and achievements.

Built with **Astro**, **React**, and **Tailwind CSS**.

## Sections

- **Home**: Profile summary, contact links, technical skills marquee, interactive skill categories, and animated matrix canvas
- **Projects**:
  - *ESP32-Based Energy Monitoring System* (`ESP32 | PZEM | OLED`)
  - *Charge Guard – EV Charger Health and Predictive Maintenance* (`12 V DC Test Rig | INA219 | DS18B20`)
- **Experience**: Industrial internships (SCG Ex d Tech Pvt. Ltd., NLC India Limited), education, certifications, and hackathon/award achievements
- **Contact**: Direct email/phone/LinkedIn details and quick email inquiry form

## Local Development

```bash
pnpm install
pnpm run dev
pnpm run build
```
